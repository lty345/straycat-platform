# 流浪猫内容平台 · MVP 边界

> 这份文件的作用：**防止项目膨胀**。
> 写下来的"不做"，比"做"更重要——过去几个项目没做完，都是因为这一栏是空的。

---

## 一句话定位

给流浪猫做内容社区：看猫、读故事、学养猫知识，从内容里获得情绪上的治愈。
**技术重点是个性化推荐**（可解释的规则版），不是"又一套 CRUD"。

---

## 这一版做（MVP）

| 模块 | 范围 | 验收标准 |
|---|---|---|
| 内容 | 发布 / 列表 / 详情 | 能分页拉取、能按标签筛 |
| 埋点 | 浏览、点赞 | 每来一次记一条，能按用户查 |
| 推荐 | 标签匹配 + 时间衰减 + 热门兜底 | `GET /feed` 对不同用户返回不同顺序 |
| 领养 | 申请（一只猫只能被一人申请） | 并发 10 个申请 → 只 1 个成功 |
| 测试 | pytest 覆盖上述核心 | 绿了才算完成 |

### 验收（整个 MVP 算完成的标准）

- [ ] 造 20 条内容 + 3 个用户 + 50 条埋点
- [ ] 两个兴趣不同的用户，`/feed` 返回的顺序明显不同
- [ ] `pytest` 全绿，覆盖：分页边界 / 埋点写入 / 推荐排序 / 领养抢占
- [ ] README 里有一节写清"推荐分数怎么算、为什么这么定权重"

---

## 这一版**不做**（写下来才能不手痒）

- ❌ 用户关注 / 评论 / 私信
- ❌ 图片上传（先用 URL 字符串）
- ❌ 协同过滤 / 向量检索 / Embedding
- ❌ App 推送 / 短信 / 邮件
- ❌ 支付、捐粮、打赏
- ❌ 后台管理界面
- ❌ 多角色权限（管理员/普通用户）
- ❌ Redis 缓存（用不上就别加）
- ❌ Docker / CI（等有第二个使用者再说）
- ❌ 前端页面超过 1 页

> 想加功能时先问一句：**它能让"推荐"这个核心讲得更清楚吗？** 不能就记到"下一版"，别现在做。

## 数据模型（三张表起步）

### `content` 内容

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int PK | |
| title | varchar | 标题 |
| body | text | 正文 |
| tags | varchar/json | 标签，如 `["橘猫","救助","科普"]` |
| mood | varchar | 情绪基调：治愈 / 科普 / 揪心 / 欢乐 |
| cover_url | varchar | 封面图 URL |
| publish_time | datetime | 用于时间衰减 |

### `cat` 猫

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int PK | |
| name | varchar | 名字 |
| breed | varchar | 品种（橘猫/狸花/…） |
| age_month | int | 月龄 |
| health | varchar | 健康状态 |
| location | varchar | 所在城市/救助点 |
| status | varchar | 待领养 / 审核中 / 已领养 |
| content_id | int | 关联的介绍内容（可空） |

### `user_event` 埋点（**推荐的燃料**）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int PK | |
| user_id | int | 谁 |
| target_type | varchar | `content` / `cat` |
| target_id | int | 哪个 |
| event | varchar | `view` / `like` |
| duration_ms | int | 停留时长（可空） |
| created_at | datetime | |

> **没有埋点就没有推荐。** 顺序上先做埋点表，再做推荐。

## 推荐算法（第一版，规则版）

```
score = 3 × 标签匹配数
      + 2 × 情绪偏好匹配（用户历史偏好看得多的 mood）
      + 1 × 同城加权
      + 0.5 × 热度（近 7 天点赞数，归一化）
      × 时间衰减：0.5 ^ (已发布天数 / 7)
```

- **冷启动**：注册/首次访问时选 3~5 个兴趣标签，直接用于"标签匹配"
- **兜底**：新用户或算不出分时，返回热门（近 7 天点赞 Top 10）
- **可解释**：每个分数都能说出"因为你也喜欢橘猫 + 这条是今天的"

> 为什么不上协同过滤：现在只有个位数用户，矩阵全是空的，算出来是噪声。
> 等有几百用户、几万条行为再考虑——那时它才有意义。
